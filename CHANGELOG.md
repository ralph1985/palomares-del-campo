# Changelog

Los cambios relevantes de este proyecto se registran aquí. El historial de Git conserva el detalle de cada commit; este archivo resume cambios aún no promocionados y releases deliberados.

## [Unreleased]

### Added

- Favicon del sitio basado en el escudo de Palomares del Campo.
- Documentación del flujo de ramas, Preview persistente y promociones a producción.

### Changed

- CI valida también los pushes a `develop` y las PRs dirigidas a `develop`.
- La Preview persistente queda documentada con su hostname y el deployment Convex de desarrollo compartido; debe utilizar datos de prueba.

### Fixed

- Los campos de texto del formulario de Palomareños usan un tamaño legible en móvil para evitar el zoom automático al enfocarlos.
