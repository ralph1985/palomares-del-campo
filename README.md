# Palomares del Campo

Web editorial de Palomares del Campo construida con Astro y Three.js.

## Documentación del proyecto

- [`AGENTS.md`](AGENTS.md): reglas que deben seguir los agentes de código.
- [`docs/architecture.md`](docs/architecture.md): arquitectura, organización del CSS y evolución prevista.

## Desarrollo

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Para comprobar la compilación estática:

```bash
pnpm run build
```
